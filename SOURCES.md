# Audio sources

Every sound shipped in Stillwater must be CC0 or self recorded. Record each file here before it is committed.

Files go in `Resources/Sounds/` named after the soundscape (`ocean`, `rain`, `forest`, `stream`, `wind`, plus `lake` and `cottage` later), as `.wav`, `.caf` or `.m4a`. The build copies them into the app; a bundled file replaces the built in synthesized version of that sound.
