# Tarn 0.1.0

A tarn is a small, still mountain lake. Tarn is a calm place to focus, and to breathe.

First release. A free, open source menu bar app for the Mac, made by Antelis Labs.

- Focus mode with Pomodoro rounds, a focus lens, guided breathing breaks, daily stats and an optional schedule
- Breathe mode with a flower or water, gentle prompts and an optional spoken guide
- Optional recorded ambient sounds, off until you turn them on
- `tarnctl` command line tool and `tarn://` links for Shortcuts and Raycast
- No account, no tracking
